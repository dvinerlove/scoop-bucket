# dvinerlove's scoop bucket

Personal [Scoop](https://scoop.sh) bucket for my apps.

```
scoop bucket add dvinerlove https://github.com/dvinerlove/scoop-bucket
scoop install dvinerlove/motu-ui
```

## Apps

- **motu-ui** — unofficial control panel for MOTU M2/M4/M6 audio interfaces.
  Requires the official MOTU M-Series driver.
